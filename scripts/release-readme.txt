Garlic {{VERSION}} — граф задач и база знаний

ЗАПУСК
  Вариант 1 (без установки): запустите Garlic.exe.
  Вариант 2 (установка с ярлыком в меню Пуск): Garlic_{{VERSION}}_x64-setup.exe.

ТРЕБОВАНИЯ
  Windows 10/11 x64 и Microsoft Edge WebView2 Runtime
  (в Windows 11 уже есть; для Windows 10 — https://go.microsoft.com/fwlink/p/?LinkId=2124703).

ГДЕ ДАННЫЕ
  База графа:      %APPDATA%\com.garlic.desktop\garlic.db
  База знаний:     Документы\Garlic Vault (папка .md-файлов, меняется в настройках,
                   совместима с Obsidian)

Исходный код: https://github.com/4p4r4t/garlic
